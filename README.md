# SHY BOI

Autonomous Evasion System v2.2 — a robotic system that simulates social anxiety by interpreting proximity as distress and executing evasion maneuvers.

## Deploy
This repo is configured for GitHub Pages. Push the `main` branch to deploy automatically at:

https://t0ttora.github.io/shy_boi/

## SEO/Assets
- index.html includes meta tags, Open Graph/Twitter, canonical, JSON-LD.
- robots.txt and sitemap.xml are added.
- site.webmanifest is added. Please provide icons at `assets/icon-192.png`, `assets/icon-512.png` and social preview `assets/og-image.png`.

## Local Preview
Open `index.html` in a browser, or serve with a static server.
